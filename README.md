# Smilex

## التشغيل

- يتطلب التطبيق Node.js إصدار 22.13 أو أحدث.
- انسخ `.env.example` إلى `.env`، ثم عيّن بريد المدير وكلمة مرور فريدة لا تقل عن 12 محرفًا. يرفض الخادم التشغيل بإعدادات إدارة غير صالحة.
- لتفعيل تأكيد البريد واستعادة كلمة المرور، أضف مفتاح Resend، وعنوان إرسال موثقًا لدى Resend، ورابط الموقع العام عبر HTTPS إلى `.env`.
- شغّل `npm start`.

عند أول تشغيل، يستورد الخادم بيانات `data/clinic.json` إلى SQLite في `data/clinic.sqlite` دون حذف ملف JSON الأصلي. احتفظ بقاعدة SQLite ومجلد `uploads` ضمن النسخ الاحتياطية، ولا تضع قاعدة البيانات على مجلد شبكي مشترك.

في النشر العام، استخدم HTTPS عبر الخادم الوكيل، واضبط `NODE_ENV=production`. لا ترفع `.env` أو قاعدة البيانات أو ملفات الوسائط إلى مستودع الشيفرة.

## الاختبارات

شغّل `npm test` لاختبارات SQLite والمعاملات والجلسات وحدود محاولات الدخول.

## الأدوار والصلاحيات

تُحدّد أدوار الفريق صلاحيات مستقلة لكل قسم: عرض، إضافة، تعديل، حذف (والرفع للوسائط والتصدير حيث ينطبق). يفرض الخادم الصلاحية المطلوبة لكل عملية؛ صلاحية العرض وحدها لا تسمح بالتغيير. تُطبّق صلاحيات الدور المخصص مباشرة على حسابات الموظفين المرتبطة به، ولا يمكن للمستخدم منح صلاحيات لا يملكها بنفسه. صلاحيات الأقسام القديمة تُعامل كصلاحية عرض فقط.
